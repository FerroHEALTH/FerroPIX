- The audit spool writes the records that arrive together as one file with one flush to the disk, and sends them to the audit repository as one batch Bundle (ihe-atna 0.24.0), so an audited transaction no longer waits for a flush of its own. `ihe-iti` and `nl-generic-functions` move to 0.19.0 on it, and `ihe_atna::atna::feed::FeedClient::post` returns a `FeedAnswer`; a dependant moves ihe-atna to 0.24 with them. A spool directory an older FerroPIX wrote holds `.msg` files the server refuses at start: let the older server deliver them, or move them out, before you upgrade.
