- Breaking: the `assertion_audience` key of an OAuth client table (`[[auth.issuer]]` introspection `client`, and every outbound `credentials.oauth` table) is removed, and a configuration that still sets it refuses to load as an unknown key. A `private_key_jwt` client assertion now takes its `aud` and `typ` from the grant's security profile: the token endpoint under `typ` `JWT` by default (SMART App Launch 2.2.0, Client Authentication: Asymmetric), or, with `security_profile = "fapi2"`, the issuer identifier under `client-authentication+jwt` (FAPI 2.0 Security Profile §5.3.3.1). Upgrade: delete `assertion_audience`; a grant that set it to `issuer` sets `security_profile = "fapi2"` instead.
