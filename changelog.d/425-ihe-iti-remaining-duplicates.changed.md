- `ihe-iti` 0.0.71 and `nl-generic-functions` 0.0.38: a client's `with_authorizer` is now the one method of the `ihe_iti::authorizer::Authorizable` trait, which the PIXm, PDQm, mCSD and NVI clients and the PMIR subscriber implement, so a caller imports the trait to call it. The FHIR search value escaping and the FHIR JSON media type check move into the new `rest` feature as `ihe_iti::rest::escape` and `ihe_iti::rest::fhir_json`, which `pixm`, `pdqm`, `mcsd`, `pmir` and the `nvi` feature of `nl-generic-functions` turn on. Every message, answer and audit record is unchanged.
