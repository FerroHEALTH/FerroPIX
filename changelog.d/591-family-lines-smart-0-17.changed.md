- Breaking for a crate user: `ihe-iti` 0.3.0 and `nl-generic-functions` 0.3.0 require `ferrohealth-smart` 0.17, whose `OutboundClient` and endpoint tables their clients are built from, and `ihe-iti` requires `ihe-atna` 0.11. In smart 0.17 every token and introspection endpoint a configuration table names is a `SecretUrl`, so a password in its userinfo reaches no rendering of the running configuration. Upgrade: take `ferrohealth-smart` 0.17 and `ihe-atna` 0.11, and build `OauthSection::token_endpoint` with `SecretUrl::new` and read it with `.expose()`. The server and the console move to `ferrohealth-smart` 0.17.0, `ferrohealth-session` 0.11.0, `ferrohealth-config` 0.4.3, `ferrohealth-server` 0.8.2, `ihe-atna` 0.11.0, `ferrobridge-term` 0.4.0 and `ferrobridge-hl7v2` 0.6.0, with no configuration key changed.
