- The Helm chart is 0.3.18. Chart 0.3.17 could not start FerroPIX 0.0.25 at its defaults: its values set `config.auth.audience`, which the server stopped reading when the audience moved into each `[[auth.issuer]]` entry, so every install, standalone or as a dependency, stopped at start with "unknown field `audience`". The values carry no audience now, the values schema refuses `config.auth.audience` by name and points at `config.auth.issuer[].audience` (in chart 0.3.18 only; the next chart version refuses it as any other value the server does not read), and the chart refuses to render without a `config.auth.issuer` entry, each with its `issuer`, `kind` and `audience`. Upgrade: move the audience into each issuer entry and give each its `kind`. CI and the release's chart leg now render the chart over every value set under `deploy/helm/ci`, the defaults among them, and run the server's and the console's `config check` over the configuration it renders, so a chart whose values its images refuse is never published.
