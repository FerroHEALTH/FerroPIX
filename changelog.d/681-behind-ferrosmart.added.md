- FerroPIX runs behind FerroSMART, the family's SMART App Launch 2.x authorization server: an `[[auth.issuer]]` table with `profile = "ferrosmart"` reads FerroSMART's RFC 9068 tokens (`typ` `at+jwt` alone, `scope` required), a person through a SMART app listed in `delegates` as delegated, and a Backend Services client as the system. The book's new page "Behind FerroSMART" gives FerroSMART's resource table, FerroPIX's issuer table and its discovery document. Breaking for crate users: `ihe-iti` and `nl-generic-functions` 0.14.0 require `ferrohealth-smart` 0.29. The server and the console move to `ferrohealth-smart` 0.29.1, `ferrohealth-session` 0.24, `ferrobridge-term` 0.13 and `ferrobridge-hl7v2` 0.19, so one smart links.
