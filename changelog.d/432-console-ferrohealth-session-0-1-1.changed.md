- The operator console takes `ferrohealth-session` 0.1.1. Its `[oidc] post_logout_redirect_uri`, like `redirect_uri`, must be an `http` or `https` URL with a host and no userinfo. The session route now answers a gone session with an RFC 9457 problem whose detail is the catalog's `session-gone`. The provider, redirect and scope rules of `[oidc]`, and the refusal of a sign-in page as a return, are the crate's now; every configuration refusal names the same key as before.
